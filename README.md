# Bottle Flip Challenge

A browser based bottle flipping game featuring five different maps, including a Kitchen Counter, Office Desk, Skate Park, Rooftop, and Moving Truck, each with unique physics such as wind and gravity differences. Progress through levels by landing the bottle upright inside the target zone.

## How to play
Open index.html in a browser, pick a map from the dropdown, and press the FLIP button to send the bottle spinning. Land it upright inside the green zone to advance levels and rack up points.
